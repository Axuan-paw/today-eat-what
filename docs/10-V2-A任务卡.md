> 对应规划：`09-V2.0规划.md` 第二节 V2-A
> 决策：数据库 **MySQL** · 访问方式 **先原生 SQL** · 前端 **V2-A 就拆**
> 预估：**1 小时** · 日期：2026-10-12

---

## 【目标】

让三个东西同时具备：

1. **Python 后端环境就绪** —— 有一个隔离的 venv，FastAPI 能在本机跑起来
2. **目录结构到位** —— `frontend/` 与 `backend/` 分开，为后续六段工作铺好路
3. **验证闭环** —— 后端能响应请求，前端仍然能正常打开

**做完这一段的标志**：浏览器能打开 `http://127.0.0.1:8000/docs`，看到 FastAPI 自动生成的接口文档页。

## 【为什么这么做】

1. **venv 隔离是底线** —— 不建虚拟环境，装包会污染系统 Python。将来 V3.0 装 LLM SDK 时，版本冲突会让你排查到崩溃。
2. **目录必须先分** —— 早拆成本低。V2-E 才拆的话，要同时改 `index.html`、`.gitignore`、测试脚本、文档路径，改动面翻倍。
3. **先验证"能跑"再写业务** —— FastAPI 跑起来了，后面每一段都是在它上面加接口；如果环境有问题，越早发现越好。

## 【做什么】五个小步，一次一个

### 小步 A-1 · 处理代理环境变量（5 分钟）

你的环境里有个**没有节点的代理**（`all_proxy = http://127.0.0.1:30810`），它会让 pip 静默失败。

**本终端临时清除**（推荐，不动系统设置）：

```powershell
$env:all_proxy=""; $env:ALL_PROXY=""
$env:http_proxy=""; $env:HTTP_PROXY=""
$env:https_proxy=""; $env:HTTPS_PROXY=""
```

**验证清干净了**：

```powershell
Get-ChildItem env: | Where-Object { $_.Name -match "proxy" }
```

**期望**：什么都不输出（或只剩 `no_proxy`）。

> ⚠️ **每次新开终端都要重做这一步**。如果想一劳永逸，需要去"系统环境变量"里删掉那几条——**但先别急**，等确认这就是元凶再说（也有可能你之后会给代理配上节点）。

### 小步 A-2 · 建目录 + 迁移前端文件（15 分钟）

```powershell
cd D:\projects\today-eat-what
```

### 小步 A-3 · 建虚拟环境（10 分钟）

```powershell
cd D:\projects\today-eat-what\backend
python -m venv .venv
```

**验证建好了**：

```powershell
Test-Path .venv\Scripts\python.exe    # 期望 True
.venv\Scripts\python.exe --version    # 期望 Python 3.14.0
```

> ⚠️ **不要依赖 `Activate.ps1`**（PowerShell 执行策略会拦它）。**后面所有命令都用 `.venv\Scripts\python.exe` 全路径调用**，绕开激活这一步，更稳。

---

### 小步 A-4 · 装依赖（15 分钟）

```powershell
cd D:\projects\today-eat-what\backend
.venv\Scripts\python.exe -m pip install -i https://mirrors.aliyun.com/pypi/simple/ fastapi uvicorn pymysql
```

**三个要点**：

| 要点 | 原因 |
|---|---|
| **用阿里云镜像** | 清华源在你这个网络返回 403；官方源能用但慢（拉一个索引页 11 秒） |
| **不要装 `uvicorn[standard]`** | 它会拉 `httptools` / `watchfiles` 等 C/Rust 扩展，可能触发本地编译。开发用纯 `uvicorn` 足够 |
| **一定要用 `.venv\Scripts\python.exe -m pip`** | 直接敲 `pip` 会装到全局 Python 上 |

**验证装上了**：

```powershell
.venv\Scripts\python.exe -c "import fastapi, uvicorn, pymysql; print('依赖 OK')"
```

### 小步 A-5 · Hello World 验证（15 分钟）

在 `backend/` 下新建 `main.py`：

```python
from fastapi import FastAPI

app = FastAPI(title="今天吃什么 API", version="2.0")


@app.get("/")
def root():
    return {"message": "今天吃什么 · V2.0 后端已启动"}


@app.get("/api/health")
def health():
    return {"status": "ok"}
```

**启动**：

```powershell
cd D:\projects\today-eat-what\backend
.venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

**验证**：

1. 浏览器打开 `http://127.0.0.1:8000/` → 看到那段 JSON
2. 浏览器打开 `http://127.0.0.1:8000/docs` → **看到 FastAPI 自动生成的接口文档页**（这是本段的最终标志）
3. 终端按 `Ctrl+C` 停止

> `--reload` 的意思是"改代码自动重启"，开发时很方便。它依赖 `watchfiles`，如果报错就去掉这个参数——**不影响功能**。

## 【三个坑，提前说】

**坑 1 · venv 激活被拦**
PowerShell 默认执行策略会拒绝 `Activate.ps1`。
**对策**：不激活，全部用 `.venv\Scripts\python.exe` 全路径调用。

**坑 2 · 移动文件后忘了改引用**
`tests/t6-logic-verify.js` 里的路径是硬编码的，`index.html` 一移动它就失效。
**对策**：A-2 里一并改掉，改完立刻跑一次验收第 4 项。

**坑 3 · 新终端忘了清代理**
代理变量是环境级的，**每个新开的终端都要重清**。
**症状**：pip 报 `Could not find a version that satisfies the requirement ...`（看起来像包不存在，其实是网络被代理吞了）。
**对策**：看到这个报错，先回头做小步 A-1。
