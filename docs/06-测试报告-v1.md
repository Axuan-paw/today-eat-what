## 一、测试方法

分两部分，原因如下：

| 部分 | 项数 | 怎么测 | 为什么 |
|---|---|---|---|
| **逻辑层** | 10 | HP 用 Node 独立复现 | 纯函数不依赖浏览器，可以自动化、可重复 |
| **UI 层** | 4 | 负责人手动操作浏览器 | 依赖真实 DOM 与网络状态，无法自动化 |

> **关于"独立复现"**：负责人先自行跑完自测并报告 10/10。HP **没有直接采信**，而是用 Node 把 `index.html` 里的脚本加载进一个假的 DOM 环境（不装任何依赖、不联网），**重新跑了一遍同样的 10 个场景**，得到相同结果。
> 复现脚本已保留：`tests/t6-logic-verify.js`

**复现命令**：

```
node tests/t6-logic-verify.js
```

期望输出 `合计 10/10 通过`，退出码 0。

## 七、结论

1. **功能全部实现**：偏好面板 → 打分引擎 → 推荐按钮 → 理由展示，链路完整
